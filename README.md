# reading-discussion

독서모임의 질문을 설계하고 대화를 진행하는 방식을 기록하고 발전시키는 공간입니다.

> 질문의 진입 난도는 낮지만, 논의의 깊이에는 상한을 두지 않는다.

> 질문의 방향은 분명하게, 답변의 방향은 열려 있게.

발제문은 참가자가 진행자의 해석을 따라가는 문서가 아니라, 책을 읽은 사람들이 각자의 생각으로 대화에 들어오는 출발점입니다. 읽기에는 부담 없고, 대화하기에는 자연스러우며, 생각하려면 얼마든지 깊어질 수 있는 발제문을 지향합니다.

## 문서

- [PRINCIPLES.md](PRINCIPLES.md) — 발제 철학과 질문 평가 기준 (**핵심 SSOT**)
- [STRUCTURE.md](STRUCTURE.md) — 질문 흐름, 사전 배포용과 현장용 구성
- [AGENTS.md](AGENTS.md) — AI와 함께 작성·검토할 때의 최소 지침
- [archive/](archive/) — 과거 및 향후 발제문의 사례 아카이브

## 운영 방식

현재 합의된 원칙과 과거 사례를 구분합니다. 과거 발제문은 참고자료이며, 현재의 원칙보다 우선하지 않습니다. 실제 모임에서 새롭게 발견한 점은 검토를 거쳐 원칙에 반영할 수 있습니다.

이 저장소는 실행 프로그램이나 자동 생성 파이프라인이 아닙니다. 사람이 읽고 고칠 수 있는 문서를 중심으로 관리하며, 향후 [eeyoremind.com](https://eeyoremind.com/)에서 연결해 공개할 수 있습니다.
