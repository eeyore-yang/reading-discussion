# reading-discussion

독서모임의 질문을 설계하고 대화를 진행하는 **철학·원칙·판단 기준의 SSOT**입니다. 특정 작품의 발제문을 만드는 작업 공간이나 자동화 파이프라인은 아닙니다.

> 질문의 진입 난도는 낮지만, 논의의 깊이에는 상한을 두지 않는다.

> 질문의 방향은 분명하게, 답변의 방향은 열려 있게.

발제문은 진행자의 해석을 따라가는 문서가 아니라, 책을 읽은 사람들이 각자의 생각으로 대화에 들어오는 출발점입니다. 읽기에는 부담 없고, 대화하기에는 자연스러우며, 생각하려면 얼마든지 깊어질 수 있는 발제문을 지향합니다.

## 문서

- [PRINCIPLES.md](PRINCIPLES.md) — 발제 철학과 질문 평가 기준 (**핵심 SSOT**)
- [STRUCTURE.md](STRUCTURE.md) — 사전 공유·현장 배포·진행자 참고자료의 역할과 설계
- [AGENTS.md](AGENTS.md) — AI와 협업할 때의 최소 지침
- [archive/](archive/) — 과거 발제문 사례(현행 규칙이나 강제 템플릿이 아님)

## 활용

새 작품을 시작할 때 `PRINCIPLES.md`를 먼저 참고하고, 문서를 구성할 때 `STRUCTURE.md`를 함께 읽습니다. AI에게도 두 파일과 `AGENTS.md`를 제공하면 됩니다. 작품별 질문·발췌·진행 상황은 각 작품의 작업 맥락에서 별도로 관리합니다.

실제 모임에서 새롭게 발견한 점은 검토를 거쳐 원칙에 반영할 수 있습니다. 과거 사례보다 현재 합의된 원칙을 우선합니다.

사람이 읽고 고칠 수 있는 가벼운 Markdown 문서로 관리하며, 향후 [eeyoremind.com](https://eeyoremind.com/)과 연결해 공개할 수 있습니다.
