# 발제문 아카이브

이 폴더는 실제로 사용했거나 배포한 발제문을 보관하는 곳입니다.

- **사례이지 규범이 아닙니다.** 과거 발제문이 현재의 [원칙](../PRINCIPLES.md)보다 우선하지 않습니다.
- 과거 문서를 현재 기준에 맞춰 소급 수정하지 않습니다. 개선된 방식은 새로운 발제문과 원칙 개정에 반영합니다.
- 작품별 문서를 추가할 때 회고나 점수, 평가 메타데이터 작성을 의무화하지 않습니다.
- AI는 관련 사례가 필요한 경우에만 이 폴더를 선택적으로 참고합니다.
- Public 저장소에 올리기 전 참가자 개인정보, 비공개 대화, 저작물의 과도한 인용 등을 확인합니다.

권장 파일명 예시: `2026-두-사람의-인터내셔널.md`. 파일 형식은 보관과 열람에 편한 방식을 선택할 수 있습니다.
